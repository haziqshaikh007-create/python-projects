# Python Learning Journey 🚀  
A collection of beginner-friendly Python projects to practice programming concepts.  

## 1. Rock Paper Scissors 🎮  
Play against the computer with randomized choices and track wins, losses, and draws.  

## 2. Quiz Game ❓  
Answer multiple-choice questions with score tracking and replay option.  

## 3. Number Guessing Game 🔢  
Guess a randomly generated number with attempt tracking.  

## 4. Adventure Quiz 🗺️  
Interactive text-based adventure where choices lead to different outcomes.  

## 6. Pig Dice Game 🎲  
Turn-based dice game with random rolls and score-based win condition.  

## 7. Madlib Generator ✍️  
Fill in blanks with words to generate funny stories.  

## 8. Timed Questions Quiz ⏳  
Answer quiz questions within a countdown timer.  

## 9. Alarm Clock ⏰  
Set a custom alarm time and play sound notification.  

## 10. Password Generator 🔐  
Generate strong random passwords with customizable length and symbols.
